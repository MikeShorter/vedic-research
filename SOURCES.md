# Sources

This document records the provenance of the Sanskrit and Vedic source texts in this repository. All texts are obtained from [SanskritDocuments.org](https://sanskritdocuments.org/), a volunteer-curated repository of Sanskrit literature in ITX, Devanagari Unicode, and other formats.

The texts themselves are public domain — the Vedas are roughly 3,000 years old, and the broader Sanskrit corpus represented here is similarly ancient. The specific digital encodings are volunteer scholarly work made freely available for personal and academic use.

## Per-file provenance

Entries below are added as each source file is re-verified against the upstream SanskritDocuments.org page and re-downloaded. The format for each entry is:

```
filename — URL — YYYY-MM-DD
```

This is a slow-fill ledger; the existing files in `data/` continue to work for the parser while verification proceeds.
