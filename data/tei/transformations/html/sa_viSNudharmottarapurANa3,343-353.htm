tatra yad darśitaṃ caiva nāradasya pura ānagha tat te 'haṃ saṃpravakṣyāmi viśvadevena viṣṇunā //

caturātmā harir yatra dharmaputratvam āgataḥ
hariḥ kṛṣṇo naraś caiva tathā nārāyaṇaḥ prabhuḥ // Vdha_3,349.6

catur-ātmā harir yatra dharma-putratvam āgataḥ hariḥ kṛṣṇo naraś caiva tathā nārāyaṇaḥ prabhuḥ //

hariḥ kṛṣṇaḥ sthit[au] vṛtte tadā lokāntare kila
naranārāyaṇau devau tapasy ugre tathā ratau // Vdha_3,349.7

hariḥ kṛṣṇaḥ sthit[au] vṛtte tadā loka-antare kila nara-nārāyaṇau devau tapasy ugre tathā ratau //

aṣṭacakre sthitau yāne bhūtiyukte manohare
ekapādau nirālambau tathaivordhvabhujāv ubhau // Vdha_3,349.8

aṣṭa-cakre sthitau yāne bhūti-yukte mano-hare eka-pādau nirālambau tathaivā urdhva-bhujāv ubhau //

dadarśa nāradas tatra tāv ubhau dīptatejasau
abhivādya gatau devau tayos tu purataḥ sthitaḥ // Vdha_3,349.9

dadarśa nāradas tatra tāv ubhau dīpta-tejasau abhivādya gatau devau tayos tu purataḥ sthitaḥ //

pādyārghācamanīyādyaiḥ pūjitaḥ saṃs tadā dvijaḥ
naranārāyaṇābhyā[ṃs] tu tatrovāsa tadāśrame // Vdha_3,349.10

pādya-ārgha-ācamanīya-ādyaiḥ pūjitaḥ saṃs tadā dvijaḥ nara-nārāyaṇābhyā[ṃs] tu tatra uvāsa tad-āśrame //

āśrama-sthaḥ sa vipra-indraḥ kadācid deva-sattamau dadarśa vighnaṃ kurvāṇau deva-karma tatha ānaghau //

bhavantau jagatāṃ nāthau bhavantau parameśvarau // Vdha_3,349.12

tataḥ kṛta-āhnik[au] prāha nāradas tau jagad-gurū bhavantau jagatāṃ nāthau bhavantau parama-īśvarau //

bhavadbhyām arcyate kaś ca daive pitrye ca kalpyate // Vdha_3,349.13

ārādhana-arthaṃ kasya iha tapasy abhiratāv ubhau bhavadbhyām arcyate kaś ca daive pitrye ca kalpyate //

pūjayāmaḥ sadā brahman daive pitrye ca kalpite
viprān devagurūn gāś ca pitṝṃś caiva jagattraye // Vdha_3,349.15

pūjayāmaḥ sadā brahman daive pitrye ca kalpite viprān deva-gurūn gāś ca pitṝṃś caiva jagat-traye //

ye 'rcayanty arcayanty eva taṃ devaṃ parameśvaram

ye 'rcayanty arcayanty eva taṃ devaṃ parama-īśvaram yo 'yam apy arcayed devaṃ tena syāt pūjito hariḥ //

vidhihīnaṃ mahābhāga sa hi sarvagato yataḥ
devasyānyasya yac cārcāṃ kartukāmo 'rcayed dharim // Vdha_3,349.17

vidhi-hīnaṃ mahā-bhāga sa hi sarva-gato yataḥ devasya anyasya yac ca arcāṃ kartu-kāmo 'rcayed dharim //

tena tasya kṛtārcā syād dvijaśreṣṭha vidhānataḥ
deve yasmāt surāḥ sarvaṃ trailokyam api yad gatam // Vdha_3,349.18

tena tasya kṛta arcā syād dvija-śreṣṭha vidhānataḥ deve yasmāt surāḥ sarvaṃ trailokyam api yad gatam //

kṛtā trailokyapūjā syād viṣṇupūjāvidhāyinā
nāsti lokeṣu tad brahma yatra nāsti janārdanaḥ // Vdha_3,349.19

kṛtā trailokya-pūjā syād viṣṇu-pūjā-vidhāyinā na asti lokeṣu tad brahma yatra na asti janārdanaḥ //

na tad apy asti lokeṣu yan na viṣṇau pratiṣṭhitam
yasmin sarvaṃ yataḥ sarvaṃ yaḥ sarvaṃ sarvataś ca yaḥ // Vdha_3,349.20

na tad apy asti lokeṣu yan na viṣṇau pratiṣṭhitam yasmin sarvaṃ yataḥ sarvaṃ yaḥ sarvaṃ sarvataś ca yaḥ //

yaś ca sarvamayo nityaṃ tasmai sarvātmane namaḥ
kṣīrodamadhye dvīpo 'sti bahuyojanavistṛtaḥ // Vdha_3,349.21

yaś ca sarva-mayo nityaṃ tasmai sarva-ātmane namaḥ kṣīra-uda-madhye dvīpo 'sti bahu-yojana-vistṛtaḥ //

tatra te puruṣāḥ śvetāḥ śaśāṅkasamatejasaḥ
upetāś ca tathā sarve cakrava[r]tyupalakṣaṇaiḥ // Vdha_3,349.22

tatra te puruṣāḥ śvetāḥ śaśa-aṅka-sama-tejasaḥ upetāś ca tathā sarve cakrava[r]ty-upalakṣaṇaiḥ //

pañcarātravidhānajñāḥ pūjayanti sadā harim
māyādeham athāsthāya devo 'pi madhusūdanaḥ // Vdha_3,349.23

pañcarātra-vidhāna-jñāḥ pūjayanti sadā harim māyā-deham athā asthāya devo 'pi madhusūdanaḥ //

tatpūjāṃ pratigṛhṇāti śirasā satataṃ hariḥ
taiḥ sārdhaṃ ramate nityaṃ taiś ca saṃpūjyate sadā // Vdha_3,349.24

tat-pūjāṃ pratigṛhṇāti śirasā satataṃ hariḥ taiḥ sārdhaṃ ramate nityaṃ taiś ca saṃpūjyate sadā //

ekāntabhāvopagatā ye bhavantīha mānavāḥ
akāmāś ca jagannātham arcayanti sadā ca ye // Vdha_3,349.25

ekānta-bhāva-upagatā ye bhavanti iha mānavāḥ akāmāś ca jagannātham arcayanti sadā ca ye //

te yānti deham utsṛjya tad dvīpaṃ śvetasaṃjñitam
aniṣyandā nirāhārāḥ sarvajñāḥ sarvadarśinaḥ // Vdha_3,349.26

te yānti deham utsṛjya tad dvīpaṃ śveta-saṃjñitam aniṣyandā nirāhārāḥ sarva-jñāḥ sarva-darśinaḥ //

sarveśvarā nityatṛptāḥ paraṃ sukham upāgatāḥ
pūjayanti hariṃ tatra divyaṃ varṣaśataṃ punaḥ // Vdha_3,349.27

sarva-īśvarā nitya-tṛptāḥ paraṃ sukham upāgatāḥ pūjayanti hariṃ tatra divyaṃ varṣa-śataṃ punaḥ //

tato 'rka-maṇḍalaṃ bhittvā aniruddhaṃ vaśanti te brahmaṃs tapobhiḥ pradyumnaṃ tataḥ saṃkarṣaṇaṃ prabhum //

vāsudevaṃ tataḥ prāpya tenaiva sadṛśās tataḥ
bhavanti sarve sarvatra sarvadā sarvaśaktayaḥ // Vdha_3,349.29

vāsudevaṃ tataḥ prāpya tenaiva sadṛśās tataḥ bhavanti sarve sarvatra sarvadā sarvaśaktayaḥ //

muktāś ca sarvaduḥkhebhyaḥ paraṃ sukham upāgatāḥ
sa tvaṃ śīghram ito gatvā śvetadvīpanivāsinaḥ // Vdha_3,349.30

muktāś ca sarva-duḥkhebhyaḥ paraṃ sukham upāgatāḥ sa tvaṃ śīghram ito gatvā śvetadvīpa-nivāsinaḥ //

paśya tvaṃ puruṣān brahman prasannaḥ sa vibhus tava
darśayiṣyati rūpaṃ tu trailokyādbhutam adbhutam // Vdha_3,349.31

paśya tvaṃ puruṣān brahman prasannaḥ sa vibhus tava darśayiṣyati rūpaṃ tu trailokya-adbhutam adbhutam //

viśvaṃ brāhmaṇaśārdūla prītaṃ madhuniṣūdanam
ekataś ca dvitaś caiva tritaś caiva mahātapāḥ // Vdha_3,349.32

taṃ tu deśaṃ gatā brahman na tair dṛṣṭo janārdanaḥ eka-antabhāva-upagatās tena yasmāj jagad-guroḥ //

kevalaṃ taiḥ śritaḥ ślokaḥ śvetadvīpanivāsibhiḥ
udīrito mahābhāgaiḥ sarvakalmaṣavarjitaiḥ // Vdha_3,349.34

kevalaṃ taiḥ śritaḥ ślokaḥ śvetadvīpa-nivāsibhiḥ udīrito mahā-bhāgaiḥ sarva-kalmaṣa-varjitaiḥ //

jitaṃ te puṇḍarīkākṣa namas te viśvabhāvana

jitaṃ te puṇḍarīkākṣa namas te viśva-bhāvana namas te 'stu hṛṣīkeśa mahā-puruṣa pūrva-ja //

aśarīrāṃ mahābhāga sarvabhūtāvahāṃ hareḥ // Vdha_3,349.36

ślokam etaṃ tu te śrutvā śrutavantas tathā giram aśarīrāṃ mahā-bhāga sarva-bhūta-āvahāṃ hareḥ //

śvetadvīpam athāsādya mṛtyum āpnoti karhicit
śvetadvīpe gatir nāsti vinā caikāntibhir dvijāḥ // Vdha_3,349.37

śvetadvīpam athā asādya mṛtyum āpnoti karhicit śvetadvīpe gatir nāsti vinā caika-antibhir dvijāḥ //

sāmānyabhāvanā bhaktā bhavantaś ca tapodhanāḥ
tapasogreṇa saṃyuktās tena me deśam āgatāḥ // Vdha_3,349.38

sāmānya-bhāvanā bhaktā bhavantaś ca tapo-dhanāḥ tapasa ūgreṇa saṃyuktās tena me deśam āgatāḥ //

sāmānyabhaktisattvāś ca punar vrajata mā ciram
bhavadbhiḥ puruṣā dṛṣṭāḥ śvetadvīpanivāsinaḥ // Vdha_3,349.39

ebhiḥ ślokais tathā dṛṣṭo bhavatīti janārdanaḥ

dhūpadīpānnapuṣpāṇāṃ tathaiva ca nivedanam // Vdha_3,349.42

ślokair bhāvena kartavyau japa-homau vijānatā dhūpa-dīpa-anna-puṣpāṇāṃ tathaiva ca nivedanam //

ślokam etaṃ paṭhed viprā namaskāre pradakṣiṇe

ślokam etaṃ paṭhed viprā namas-kāre pradakṣiṇe snānam etena kartavyaṃ tathā ca ante jalaṃ dvijāḥ //

sarvapāpaharaṃ puṇyaṃ mokṣadaṃ sarvakāmadam

sarva-pāpa-haraṃ puṇyaṃ mokṣa-daṃ sarva-kāma-dam śloka eṣa vinirdiṣṭaḥ sarva-kāma-pradaḥ śivaḥ //

etasya jāpaḥ kartavyo nityam eva vijānatā // Vdha_3,349.45

samāpayām āsa tadā taṃ yajñaṃ pārthivasya ca eka-anta-bhāvopagatā ṛṣayo 'pi janārdanam //

āgatā deva-kārya-arthaṃ śvetadvīpāt purā dvija śvetadvīpaṃ punaḥ prāptaṃ punar-āvṛtti-durlabham //

śvetadvīpa-gatasya api tena te dvija sāmpratam na bhaviṣyati lokeṣu gatir nirvāṇa-kāriṇī kalpa-avasāne tu gatiṃ tāṃ tvaṃ vipra gamiṣyasi //

ahaṃ bhūtaṃ ca bhavyaṃ ca vartamānam ahaṃ tathā

ahaṃ bhūtaṃ ca bhavyaṃ ca vartamānam ahaṃ tathā sthāvaraṃ jaṅgamaṃ caiva sarvam eva asmi nārada //
